## 폰트 원본과 용량

Pretendard 1.3.9의 정적 OTF와 `@expo-google-fonts/noto-serif-kr` 0.4.4의 정적 TTF를 변환·서브셋 없이 포함했다. 각 라이선스와 파일별 출처·SHA-256은 `assets/fonts/sources.json`에 있다. 여섯 파일은 합계 47,010,056바이트(약 44.8 MiB)다. 폰트 로딩 전 본 화면을 대체 폰트로 표시하지 않는다. 웹 첫 설치 및 오프라인 캐시에 이 용량이 추가된다.

## 명세 내부 충돌 — 임의 색상 변경 없음

명세는 지정 HEX와 모든 텍스트 WCAG AA를 동시에 요구한다. WCAG 상대 휘도 공식으로 계산하면 다음 일부 조합은 일반 크기 텍스트 기준 4.5:1에 미달한다.

| 전경                | 종이 `#FAF6EB` | 샌드 `#EEE6D5` |
| ------------------- | -------------- | -------------- |
| 보조 글자 `#6B7563` | 4.471:1        | 3.889:1        |
| 강조 `#61785C`      | 4.471:1        | 3.889:1        |
| 주요 글자 `#344B3C` | 8.769:1        | 7.627:1        |

사용자의 “너 맘대로 수정하지말고” 지시에 따라 HEX를 유지했다. AA 전체 충족이라고 주장하지 않는다. 대비 보정을 하려면 사용자가 색상 변경 범위를 정해야 한다.

## 연결되지 않았거나 실기기에서 확인하지 못한 항목

- 클라우드 제공자/계정/서버가 지정되지 않았다. 기존 파일 백업·공유·파일 선택 복원을 유지한다. 네이티브 파일 공유로 iCloud Drive/Google Drive 등에 사용자가 보관할 수 있으나 자동 클라우드 동기화 서버를 임의로 만들거나 연결하지 않았다.
- 실물 iPhone/Android의 키보드·글꼴 1.35배·햅틱·스크린리더·터치 스와이프·SQLite 런타임은 미실행이다. 브라우저 뷰포트 축소와 iOS/Android Hermes 번들 생성은 이를 대체하지 않는다.
- 광고·결제는 테스트 모드다. 선택형 Groq는 기존 별도 동의·연결 구조를 보존했으며 실제 API 호출은 실행하지 않았다.
- 공식 연도별 추석 데이터는 기존과 같이 미제공 상태다. 날짜를 추정해 운영 시즌을 추가하지 않았다.

최종 실행 결과는 루트 `VALIDATION.md`, 화면 비교는 `docs/ui-review.html`과 `docs/screenshots/00~09`를 확인한다. 기존 `prototype/` 보존본, 도메인 규칙, 백업 v1/v2/v3 및 DB user_version 3을 유지한다.
