# 작은 행동 중심 제품 복원

## 구현

홈의 우선순위는 다음 실제 행동 → 식물 성장 → 생각 꺼내기 → 접을 수 있는 목표 트리 → 선택적 하루 회고다. 기록 달력은 보존하지만 홈의 중심에서 내렸다. 완료가 없거나 오랜만에 접속해도 기분만 저장하거나 건너뛸 수 있다. 감정 기록·접속·타이머는 성장 보상을 주지 않는다.

각 목표는 parentId로 하위 단계를 보존한다. 최대 8단계까지 나눌 수 있고, 실행 화면은 활성 조상 아래의 가장 작은 행동 하나만 보여준다. 모든 직접 자식이 완료되면 부모가 자동 완료된다. 자동 완료에는 aggregate 표시를 붙여 완료 수·성장·꽃의 행동 기록에 중복 포함하지 않는다. 진행률은 완료한 말단 행동 / 전체 말단 행동이다. 하위 행동을 추가로 나누면 분모가 바뀔 수 있다. ‘나중에’는 해당 가지를 씨앗으로 보관한다. 미완료 목표 삭제 시 이미 완료한 행동 기록은 보존한다.

Groq 서버는 목표 → 단계 → 행동 JSON을 제안하며 루트 evidence를 원문과 대조한다. 제안은 사용자 검토 후만 저장된다. 구버전 서버의 평면 결과도 앱에서 규칙 기반 단계 제안으로 보완한다. 기본 오프라인 제안은 목표별 준비 행동과 실행 행동이며 구체적인 상황을 이해하는 AI가 아니다. 필요한 경우 사용자가 더 작게 나눈다. AI 실패 시 원문과 기기 내 정리를 계속 사용할 수 있다. 실제 Groq 운영 키로 요청한 결과는 검증하지 않았다.

화면이나 브랜드 이미지를 복제하지 않았다. 작은 행동을 가장 크게, 맥락과 진행률은 그 아래, 생각 입력과 회고는 독립 카드로 구분했다. 주요 조작은 48px 이상, 색 외의 완료 텍스트·개수, 스크린리더 이름·펼침 상태·진행값을 제공한다. 기존 모션 감소 설정을 유지한다. 실기기 VoiceOver/TalkBack 및 사용성 조사는 별도 확인이 필요하다.

## 데이터 이전과 되돌리기

상태 및 SQLite user_version을 4로 올린다. 기존 v1/v2/v3는 기존 변환 후 v4로 승격하며 기존 ID, 순서, 원문, 일기, 회고, 꽃 확률·색·등록 여부·성취 수는 바꾸지 않는다. 과거 평면 작업의 부모를 추정하지 않는다. 기존 저장 위치와 백업 컨테이너 형식은 유지한다. 새 백업의 내부 version=4로 구버전 앱의 복원을 차단한다. SQLite 변경은 기존 배타적 트랜잭션 안에서 수행해 실패 시 롤백한다. 웹은 읽을 때 메모리에서 검증·변환하고 다음 저장에서 원자적 IndexedDB 트랜잭션으로 반영한다.

업데이트 전 기존 앱에서 백업을 내보내는 것이 롤백 방법이다. v4 사용 후 v3 앱으로 돌아가면 새 데이터는 지원되지 않으며 업데이트 전 백업을 복원해야 한다. v4 데이터를 v3로 강제 낮추지 않는다. 순환·고아·과도한 깊이·부모와 자식 완료 불일치는 복원하지 않는다. 이전의 손상된 데이터도 자동 초기화하지 않는다.

## 실행과 배포 경계

```sh
npm ci
npm test
npm run check
npm run export:preview
npx playwright install chromium
npm run test:actions
npm run preview:mobile
```

브라우저가 기본 설치 위치가 아니면 CHROMIUM_PATH를 지정한다. `test:mobile`은 새 제품 흐름을 검증한다. 이전 일기 홈 전용 화면 테스트는 `test:mobile:legacy`로 남겼으며 새 홈의 수용 기준이 아니다. 원본 보존·확률·보상·SQLite 테스트는 모두 기본 `npm test`에 포함된다.

PR의 `Verify small-action product flow`는 테스트·웹 번들·실제 브라우저 검증 후 미리보기와 스크린샷을 Actions artifact로 제공한다. 이 작업은 gh-pages나 Vercel에 게시하지 않는다. 기존 feat/expo-onjeom에는 push 시 Pages를 배포하는 워크플로가 있으므로 PR 병합은 실제 사이트 갱신을 유발할 수 있다. 이 개발 브랜치는 병합하거나 프로덕션에 배포하지 않는다. Expo web 성공은 iOS/Android 설치·서명·스토어 배포나 실제 Groq 서버 배포를 의미하지 않는다.
