# Codex에 전달할 실행 요청

이 저장소의 `AGENTS.md`, `README.md` 및 `src/logic.mjs`를 우선 읽고 작업을 시작해 주세요.

목적: '온점.'의 웹 프로토타입을 토대로 한국어 iOS/Android 앱의 첫 번째 실행 가능한 React Native/Expo MVP를 만드세요.

1. Expo 최신 안정 SDK와 실제 iPhone 개발 빌드 호환성을 공식 문서로 확인하여 프로젝트를 구성하세요. 이 웹 프로토타입의 시각적 톤(크림/세이지/수채화 느낌)을 유지하되, 네이티브 탐색 구조를 갖춥니다.
2. 기능: 자유 생각 입력, 목록 분리(현 규칙 기반 로컬 구현을 보존), 사용자 수정, 한 번에 한 작업 표시, 완료·나중에·작은 단계, 4개 완료 시 꽃 1송이 개화, 꽃 12종, 변이, 고정일 시즌 꽃, 미등록 꽃 보관, 꽃말 카드·도감, 미완료 씨앗 복원, 로컬 데이터 저장/삭제.
3. 광고: 새 품종+색상 도감 첫 등록에서만 보상형 광고를 제안하는 흐름을 **테스트용 명확한 mock**으로 유지합니다. 광고 취소 시 꽃은 그대로 보관. PLUS 데모 토글은 실제 과금 아님을 표시. 실광고/인앱결제를 사용자가 승인하고 SDK·계정 설정을 제공하기 전에는 진행하지 마세요.
4. AI: 현재 코드는 정규식 기반임을 UI/README에 표시합니다. 향후 실제 AI API를 연결할 수 있도록 인터페이스를 분리하되 사용자 동의와 백엔드 없이 API 호출을 도입하지 마세요.
5. 계절: 12/18~12/26 크리스마스, 10/24~11/1 할로윈, 12/30~1/3 새해. 추석은 매년 양력 날짜가 달라 명시적 연도별 데이터가 필요하며 임의 날짜를 쓰지 마세요.
6. tests: 작업 상태, 꽃 생성, 도감 최초 등록/중복 등록, 시즌 날짜, 데이터 저장, 광고 취소 시 동작을 자동 테스트로 검증하세요.
7. 끝나면 실제로 실행한 검증과 못한 검증을 구분해 보고하고, 변경된 파일과 실행 명령을 안내해 주세요.
